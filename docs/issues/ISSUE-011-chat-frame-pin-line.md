# Issue: 聊天框常在，修正白点和连线

> 状态：已确认并实现。P0、P1 离线通过。P2 已在浏览器核对空聊天框、透明标点和最后一天的线。

spec: SPEC-007。本任务只补三处，不改行程卡编号和「点第几天只画这一天」。

## 用户原话（2026-10-22）

把提问框放到聊天记录框下边。不是取消聊天框、等有内容了再刷新出来，而是这个框一直在，有内容就加进去。白点问题要修正。连线问题也要修正，只要满足连线的条件就去连线。

## 要改

- 左边聊天记录框打开页面就在，空的时候也在。提问框固定在这个框下面。
- 新的问答加进这同一个框，不把框拆掉再换一块新区域。
- 标点不再是一块大白底。建议：白底改成透明，只留现在这种小的颜色数字圆点。
- 连线条件仍是：这一天里有坐标的地点不少于 2 个。满足就画线，包括最后一天。只有 1 个点时仍然不画线。

## 不改

- 右边地图栏、默认的中国范围空地图。
- 「第 1 天 / 第 2 天」按钮。不用滑动条代替。
- 点哪一天，地图只画这一天的线。不改成所有天的线同时铺开。
- 行程卡编号、选中哪张卡就画哪一次、只问天气不换地图。
- 坐标怎么补、按天颜色、同一轮搜索和天气各一次。
- 点上仍只显示序号，全名仍在点击后的气泡里。

## 规格未写、合理用户会踩

| 输入或情况 | 合理用户期望 | 落到哪条测试 |
