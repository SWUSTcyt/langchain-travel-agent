## 任务描述

宿主在调用地图工具前写入城市。写入失败则不调用该工具。

本轮模型输入只包含：仍生效的城市/天数/节奏、上一轮用户原话、上一轮最终答案、当前这句。

不包含：更早轮次、思考过程 HTML、调试日志、上一轮工具原文。

本句没有城市时，沿用上一轮城市。本句出现新城市时，替换。本句提到天数时，更新天数。
