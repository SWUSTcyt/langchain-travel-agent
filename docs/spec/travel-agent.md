# Spec: 旅行对话 Agent

本版已被 `SPEC-005` 取代，只读。AC-001 至 AC-008 由 SPEC-005 原样继承。

继承 `SPEC-001` 的全局边界和技术约束。本文只写这个能力特有的行为。

## 一句话描述

用户在当前网页会话里问行程或天气；助手按需要调用高德，并让本会话里最近一次提到的城市、天数、节奏继续生效。

## 核心功能

- [x] 根据当前这句话调用高德的地点搜索、路线或天气，再给出回答
- [x] 本句没提城市时，沿用本会话里最近一次提到的城市；本句提到了就换成新的
- [x] 本句没提天数或节奏时保持原值；提到了就更新
- [x] 模型每轮只看到：行程状态、上一轮原话、上一轮最终答案、当前这句
- [x] 地图工具执行失败时，失败要可见，不能变成一段普通建议交给模型当成查到了（ISSUE-003）

## 边界条件（不在范围内）

- 不扫描更早轮次的助手回复或工具原文来恢复城市。更早的用户原话只用来算行程状态，不发给模型。
- 不把「第一天」「第十二天」「第3天」当成行程天数。
- 内置城市表没覆盖的城市（如丽江），宿主不从这句话里提取；模型若已填了 city，宿主不得改回上一轮城市。
- 不做跨天、换设备之后还能接着聊的记忆。刷新页面或清空对话后，从空会话开始。
- 不新增知识库、向量检索或城市百科。

## Agent 方案

| 项 | 选择（或不需要） | 没选什么、为什么 |
|---|---|---|
| 控制方式 | ReAct：模型决定要不要调工具，中间件在调用前改写或拦住。主路径只有这一条 | 不选一次请求：天气和地点必须查高德。不选先规划再执行：问题通常一轮工具能做完。不选多 Agent：一个助手就能答，拆开没有独立验收 |
| 谁做决定 | 宿主写死：目标城市怎么补、城市注入失败就停止该工具、工具轮次超过 `MAX_TOOL_ROUNDS`（现为 1）就停止、图的递归上限 40。模型决定：调哪个工具、选哪些地点、最终措辞。模型不能自己把失败宣布成已查到 | 不把停不停交给模型：工具循环和城市串线会直接答错。只读查询不加人确认 |
| 工具与业务技能 | 运行时工具是高德 MCP 的地点搜索、路线、天气，只读。宿主校验：地图工具必须带城市；注入失败不调用工具；工具自己抛错不算注入失败。没有业务技能包 | 编程用的 LangChain Skill 只帮助写代码，不是运行时工具 |
| 上下文与记忆 | 两层。结构化状态：本会话用户原话里，城市、天数、节奏各取最近一次提到的值，本轮重算后随请求传入。近期窗口：模型只接收紧邻上一轮的用户原话和最终答案，加上当前这句。清空或新开会话则状态为空。字段覆盖规则：本句提取到城市就整组替换，提取不到就保留；天数、节奏同理 | 不把全部历史和工具原文放进窗口：又贵又会把旧城市带回来。不用摘要：状态字段和上一轮原文够用。不用跨会话存储：刷新即空，是已确认行为 |
| 知识库与召回 | 不需要知识库。地点和天气的事实来自当次高德工具返回，用完不入库。没有稳定编号的资料要查，也不建向量索引 | 不建向量库：用户已确认不做。工具返回只是本轮候选，不是可以留到以后的事实 |
| 运行边界 | 不做外部写入，不做沙箱，不做长任务暂停恢复，不做上线前的自动评测门禁。工具失败必须留下可见失败，不能当成成功观测。界面可以继续流式显示思考过程和最终答案 | 只读查询不加确认框 |
| 用户/调用方路径 | 信息够就直接查。本句改了城市或天数，这一轮就按新值。执行中能看到思考过程和最终答案分开出现。失败后输入框里已发送的对话还在，除非用户点清空。新标签页或刷新不继承上一页的城市 | 不在开查之前追问城市：本会话已有城市就沿用；都没有时由模型从这句话判断，宿主不编一个城市 |

## 用户使用路径与信息架构

- 核心任务主线：在输入框里说出出行需求，看到针对该城市的回答。
- 关键路径步骤：打开本地页面 → 输入需求并发送 → 看到思考过程与最终答案 → 用下一句修改天数或换城市 → 得到沿用或更新后的回答。高频动作是发送追问。
- 主内容：对话区（气泡、输入框、发送、示例问题）。
- 次要内容：右侧调试面板。过程日志默认折叠；原始事件只在开发者模式出现。
- 端到端可验收场景：见 AC-002、AC-003、AC-005。
- 评审入口与版本：不需要新原型。本次不改布局。现有页面就是入口，启动方式是本地 `python main.py`。
- 确认范围：布局以 SPEC-003 为准。2026-10-20 用户确认的是「先补 Agent 方案，再按它做后续优化」，没有提出新的页面改动。
- 未展示页面如何继承：没有登录页、设置页。清空对话就是把当前会话历史清掉，下一句从空状态开始。

证据等级：E0 自动可复现，E1 人在页面上确认，E2 外部服务，E3 推断。E2/E3 不能单独当作已验收。

| ID | 验收项 | 级别 | 证据等级 |
|---|---|---|---|
| AC-001 | 城市注入失败时不调用该地图工具 | P0 | E0，`test_map_tool_not_called_when_city_injection_fails` |
| AC-002 | 上一轮是表内城市、本句是表外城市且模型已填 city 时，工具收到的是本句城市 | P0 | E0，`test_unlisted_city_named_now_is_not_overwritten_by_previous_city` |
| AC-003 | 本句没提城市时，工具没填 city 则补本会话最近城市；本句改了天数则用新天数 | P0 | E0，`test_followup_without_city_keeps_previous_city_and_updates_days` |
| AC-004 | 发给模型的消息只有上一轮用户原话、上一轮最终答案、当前句；不含思考 HTML、更早轮次和工具原文 | P0 | E0，`test_only_previous_final_answer_is_kept` |
| AC-005 | 空历史的新请求不带另一段对话的城市和天数 | P1 | E0，`test_new_session_does_not_inherit_other_session_city` |
