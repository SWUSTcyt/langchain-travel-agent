# Spec: 左列对话与可切换的行程卡

继承 SPEC-006。只改左边怎么连续显示问答，以及一次问答的行程怎么对应右边的地图。坐标来源、按天颜色、工具次数、点上只留序号，都不在这里改。

2026-10-22 用户确认这版设想，并要求先写下规划再改。

## 一句话描述

左边整列是对话：问过的话和每次回答都留着，输入框在这一列底部。写出了几天行程的回答是一张可选中的卡片。选中哪张卡，地图就画哪一次；再点这张卡里的第几天，只画这一天。

## 已经定下的规则

- 只问天气、没有几天行程的回答是普通文字。点它不换地图。
- 每次行程卡有自己的编号。天数和每一站的编号都带上这个编号，避免两张卡的「第 2 天」混在一起。
- 一句结束时把这份行程的坐标存进这张卡。之后点卡片或点某一天，用这份存好的坐标重画点和线，不重新问高德，也不重新让模型写。
- 地图对象留着，不因为点了一下就拆掉重建。
- 新的一句在地点回来之前，地图先回到没有点的默认图。对话里上一张卡还在。
- 这句没查到，或只问天气：地图回到上一张有点的行程卡。
- 新的一张行程卡出现后，默认选中它的第 1 天。
- 清空对话时，这些记录一起丢掉，地图回到默认图。
- 三张示例留在还没提问时的左列。开发者一栏仍在整页底部。

## 边界

- 不改坐标补全、按天颜色、同一轮搜索和天气各一次。
- 模型上下文仍只带上一轮原话和最终答案，不把每一张卡的坐标塞进模型。
