# Spec: 结果页作为唯一页面

继承 SPEC-004。只改「打开时是不是另一页」和「点旁边的长名字」。文字行程、按天分色、坐标来源、工具次数都不在这里改。

2026-10-22 用户确认后冻结。SPEC-004 的其余条款仍有效；本文件只改「空的时候收成另一页」和「点旁边铺全名」。只问天气不再把地图栏藏起来，这一点改掉 SPEC-004 的 AC-004。

## 一句话描述

打开就是左边文字、右边地图。提问留在这一页。还没有地点时地图给一张默认图，查到地点后再换成那些点。点上只留序号，名字在点击后的气泡里。

## 用户原话（2026-10-22）

结果页好看，左边对话、右边地图。不要两个页面的切换，提问就在这一页问。地图可以先给默认的，有了正确地点再刷新。杭州测试时，每个坐标点的文字太长，把地图挡住了。

## 建议，待确认

这些是根据原话做的建议，还不是已同意的决定：

- 默认图是中国范围的空地图，没有点、没有线，图例写「还没有地点」。不拿上一座城市的行程当默认。
- 新问题一开始先回到这张默认图，避免杭州还显示成都。查到新地点后整张换掉。
- 这次没查到：把刚才那张行程图放回去。本来就没有行程时，停在默认图。这是为了不冲掉 SPEC-004 的「失败留原图」。
- 只问天气：地图这一栏仍在。已有行程就留着，没有就显示默认图。不再把地图整栏藏起来。这会改掉 SPEC-004 的 AC-004「只问天气不显示地图」。
- 三张示例留在左边文字区，不单独占一页。
- 没有 JS key 时，右边仍占一栏，写「地图暂不可用」，文字照常。

## 边界

- 不改坐标补全、按天颜色、同一轮搜索次数。
- 不改成独立前端，仍是 Gradio 里的高德 JS。
- 线上的点不铺开全名。全名只在点击后的气泡和左侧文字里。

## 验收总纲

- P0：刚打开时右边就是地图栏，不是把页面收成中间一条。新问题在地点回来前显示默认图，不留上一座城市的点。
- P0：点上可见的只有序号。地点全名不出现在常驻标记里。点击后的气泡仍有全名。
- P1：没查到时恢复上一张行程图。只问天气不把地图栏藏起来。
